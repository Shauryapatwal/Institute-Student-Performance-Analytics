# Institute & Student Performance Analytics | MySQL

This project uses MySQL to analyze institute data and generate insights into student performance, fee collection, placements, faculty performance, and batch utilization.

## SQL Concepts Used

- Filtering, sorting, aggregation, GROUP BY, and HAVING
- Joins, subqueries, CTEs, and window functions
- Conditional logic using CASE and conditional aggregation
- Date functions and ranking techniques
- Views, stored procedures, transactions, and indexes
- Query performance analysis using EXPLAIN

## Project Outcome

This project demonstrates the application of SQL for data cleaning, relational data analysis, business reporting, and operational decision-making in an educational institute.
